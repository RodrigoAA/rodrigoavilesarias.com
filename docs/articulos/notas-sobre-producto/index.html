Otro ejemplo. Sustitúyelo por un artículo tuyo.

Tres ideas que repito mucho:

  1. El problema primero. Si no está bien nombrado, la solución es teatro.
  2. Menos superficie. Cada pantalla, flag o excepción tiene un coste oculto.
  3. Cerrar el loop. Una métrica o una conversación con usuarios vale más que otra slide.

Cuando escriba en serio aquí, estos puntos tendrán historias detrás.
